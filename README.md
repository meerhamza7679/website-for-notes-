# CS Notes Archive

A clean, sober university notes portal for storing computer science notes in JPEG format.

## Features

- Subject-based landing page for major computer science topics
- JPEG upload support for each note
- Local browser storage for persistent note archiving
- Minimal interface for quick revision browsing

## Run locally

From this folder, start a simple static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

Uploaded notes are stored in browser local storage, which preserves the archive in the current browser profile.
